# ComfyUI-DressMorph

轻量 ComfyUI 换装合成节点，无需 VideoHelperSuite。内置轻量抠图描边节点，一条龙完成换装工作流。

## 换装转场节点

- `DM 视频帧加载`
- `DM 贴纸飞入换装`（旧单次版）
- `DM 点击拾取换装`（旧单次版）
- `DM 六贴图连续点击`（推荐，有状态菜单）
- `DM 左侧贴图飞升换装`（新，贴图左侧单列升入 + 顶位飞出触发换装）
- `DM 导出 MP4`

### DM 六贴图连续点击

从第 1 帧持续显示六张独立透明贴图，按 `LT,LM,LB,RT,RM,RB` 依次播放动画鼠标点击、贴图自动飞向切片并严丝合缝遮挡、完成后永久删除被使用的贴图。

切片位置与大小由 U²-Net Lite 对每一段「下一视频」的首帧自动检测，无需手工设置 XY / 高度参数。贴图在落点处通过非均匀缩放精确贴合切片包围盒，过程中贴图尺寸不会超过切片人物。

**贴图本体对齐切片**：贴图本体（不含白色描边）与切片包围盒重合，白色描边刚好覆盖在切片外圈，不会遮住切片内部。`outline_px` 参数需与上游 `LC 抠图描白边` 节点的 `outline_px` 保持一致，用于反推原始人物轮廓。

### DM 左侧贴图飞升换装

N 张贴图（≤6）在视频**左侧单列**纵向排列，所有贴图**同时从视频中间开始垂直匀速上升**。当顶位贴图到达**视频左边顶端**（顶部留 `rise_top_y` 比例空间）时：

- 顶位贴图**飞向中央人物**，与人物轮廓严丝合缝重合（ease-out 飞行 `trigger_hold_frames` 帧）
- **视频切换**到下一段（飞行阶段使用下一段视频的前几帧作背景）
- 顶位贴图淡出消失

队列里其他贴图**继续上升**，下一张成为顶位，循环 N 次。

**上升速度自动适配**：每段视频 `video_i` 期间，顶位贴图从当前 Y 升到顶端的时间**刚好等于 `len(video_i)` 帧**。速度 = (当前Y - 顶端Y) / len(video_i)，无需手动设置。

按贴图数量自动适配：少于 6 张时，未连入的 sticker/mask 接口留空即可。

参数速查：

| 参数 | 默认 | 说明 |
|---|---|---|
| `rise_top_y` | 0.05 | 顶端 Y（视频高度比例，留 5% 顶部空间） |
| `rise_stagger` | 0.30 | 相邻贴图初始 Y 间距（视频高度比例） |
| `menu_x` | 0.12 | 队列 X 位置（视频宽度比例） |
| `rise_start_y` | 0.50 | 第一张贴图初始 Y（视频高度比例，0.5 = 中间） |
| `trigger_hold_frames` | 6 | 顶位飞到切片的帧数（含淡出） |
| `menu_size_ratio` | 0.16 | 队列贴图尺寸（占视频高度的比例） |
| `outline_px` | 5 | 与上游 LC 抠图描白边节点保持一致（-1 = 无描边） |
| `invert_loadimage_mask` | false | LC_Sticker 出来的 MASK 不需要反相 |

相对视频路径从 `ComfyUI/input` 读取，MP4 写入 `ComfyUI/output`。

## 轻量抠图节点

- `LC 抠图描白边（U²-Net Lite）`

- 输入普通 JPG/PNG 人物图
- 自动生成前景人物 MASK
- 自动添加白色描边
- 输出可直接连接到 `DM 六贴图连续点击`

模型位置：`ComfyUI/models/u2net/u2netp.onnx`

连接到六贴图节点时，请把 `invert_loadimage_mask` 设置为 `false`。
